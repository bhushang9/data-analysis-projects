# 🚗 BMW Car Data Analysis — EDA with Python

A clean Exploratory Data Analysis (EDA) of BMW car listings to understand pricing trends, model popularity, mileage patterns, and factors influencing car value.

---

## 📌 Project Overview
This project performs a full EDA workflow using Python.  
It includes data cleaning, statistical exploration, visualizations, insights, and conclusions based on the BMW dataset.

---

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 📂 Workflow

### 1. Importing Libraries
Import all necessary libraries for data manipulation and visualization.

### 2. Loading the Dataset
- Read the CSV file  
- Display basic rows  
- Inspect dataset structure  

### 3. Basic Information
- Dataset shape  
- Column datatypes  
- `.info()`  
- `.dtypes`  

### 4. Data Cleaning
- Handling missing values  
- Removing duplicate rows  
- Fixing inconsistent datatypes  

### 5. Unique Value Exploration
- Count unique values  
- Distribution of categorical features  

### 6. Statistical Summary
- Descriptive statistics for numerical features  
- Identify outliers & ranges  

---

## 📊 Exploratory Data Analysis (EDA)

### **Univariate Analysis**
- Histograms for numerical columns  
- Countplots for categorical variables  

### **Bivariate Analysis**
- Scatterplots (Price vs Mileage, Price vs Year, etc.)  
- Boxplots (Price across Transmission, Fuel Type, Model)  
- Correlation Heatmap  

---

## 🧠 Key Insights (Examples)
- Newer car models typically have higher prices  
- Mileage is negatively related to price  
- Automatic transmission cars often exhibit higher price ranges  
- Engine size positively correlates with car price  

---

## 📌 Conclusion
The analysis highlights key factors affecting BMW car prices and gives valuable insights for buyers, sellers, and pricing strategy optimization.
